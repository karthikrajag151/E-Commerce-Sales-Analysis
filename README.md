# E-commerce Data Cleaning, Analysis & Visualization with Excel

## 📌 Project Overview

This project focuses on cleaning, transforming, analyzing, and visualizing e-commerce sales data using Microsoft Excel. The objective is to transform raw sales data into a structured, reliable, and meaningful dataset that supports business decision-making.

As an aspiring Data Analyst, I developed this project to demonstrate my practical skills in data preparation, Excel formulas, lookup functions, descriptive statistics, Pivot Tables, charts, and interactive dashboard development.

The project follows a typical data analytics workflow, from importing and cleaning raw data to identifying patterns, communicating insights, and recommending business improvements.

## 🎯 Project Objectives

* Import and organize the e-commerce dataset using Excel tables.
* Identify and remove duplicate records.
* Detect and handle missing values and inconsistent data.
* Correct formatting errors and validate data quality.
* Remove irrelevant columns where necessary.
* Apply Excel formulas and functions for calculations and analysis.
* Use XLOOKUP or VLOOKUP to combine related tables where applicable.
* Create Pivot Tables and PivotCharts to summarize business performance.
* Calculate descriptive statistics to understand the distribution of numerical variables.
* Develop charts and an interactive dashboard to communicate key findings.
* Generate actionable business recommendations based on the analysis.

## 🔄 Project Workflow

### 1. Data Import and Organization

* Imported the raw dataset into Microsoft Excel.
* Reviewed the available columns and records.
* Organized the data into structured Excel tables.
* Applied suitable data types and formatting.
* Prepared the dataset for cleaning and analysis.

### 2. Data Cleaning and Transformation

Data cleaning was performed to improve data quality and ensure reliable analysis.

The cleaning process included:

* Identifying duplicate records and removing confirmed duplicates.
* Checking missing values and deciding how to handle them.
* Standardizing inconsistent text entries and category names.
* Correcting date, number, currency, and text formatting issues where applicable.
* Validating numerical values and categorical fields.
* Removing irrelevant columns where necessary.
* Documenting significant cleaning decisions.

**Outcome:** A more consistent and analysis-ready dataset.

### 3. Excel Formulas and Functions

Excel formulas were used to calculate metrics, categorize records, and extract useful information.

| Function          | Purpose                                                   |
| ----------------- | --------------------------------------------------------- |
| SUM               | Calculate total values for relevant numerical fields.     |
| AVERAGE           | Calculate average sales or other numerical measures.      |
| COUNT / COUNTA    | Count numerical entries or non-empty records.             |
| IF                | Apply conditional logic and classify records.             |
| COUNTIF / SUMIF   | Count or aggregate records based on specified conditions. |
| TEXT              | Format values or extract meaningful text representations. |
| XLOOKUP / VLOOKUP | Retrieve matching information from related tables.        |

Additional functions were applied where appropriate to support the analysis.

### 4. Descriptive Statistical Analysis

Descriptive statistics were used to understand the distribution and variability of numerical data.

The analysis included:

* **Mean:** Identify the average value.
* **Median:** Determine the middle value.
* **Mode:** Identify the most frequently occurring value.
* **Minimum and Maximum:** Understand the range of values.
* **Standard Deviation:** Measure the variability of numerical observations.
* **Count and Sum:** Understand the number of observations and aggregate values.

These measures help identify typical values, variations, and potential anomalies in the dataset.

### 5. Data Summarization Using Pivot Tables

Pivot Tables were created to summarize the dataset and explore relationships between relevant variables.

Depending on the available columns, the analysis may include:

* Sales performance by product or category.
* Revenue contribution by region or customer segment.
* Monthly or yearly sales trends.
* Comparisons across brands or product groups.
* Identification of high-performing and low-performing segments.

Calculated summaries were used to support comparisons and identify patterns in the data.

### 6. Data Visualization

Charts were developed to communicate analytical findings clearly.

The visualization stage included at least three chart types, selected according to the available data and analytical objectives:

* **Column Chart:** Compare performance across products, categories, or periods.
* **Bar Chart:** Rank or compare business segments.
* **Pie Chart:** Show the proportional contribution of categories when appropriate.
* **Line Chart:** Examine sales trends over time, if date information is available.
* **Sparklines:** Display compact trends within tables, where useful.
* **PivotCharts:** Provide visual summaries linked to Pivot Tables.

Charts were designed with appropriate titles, labels, and formatting to improve readability.

### 7. Interactive Dashboard Development

An Excel dashboard was developed to present important metrics and visual summaries in a single view.

The dashboard can include:

* Key performance indicators (KPIs).
* Sales and revenue summaries, where supported by the dataset.
* Category or product performance comparisons.
* Trend visualizations, if time-based data is available.
* PivotCharts connected to Pivot Tables.
* Slicers or other interactive filters, where implemented.

The dashboard is intended to help users explore the data efficiently and understand business performance without reviewing every record manually.
